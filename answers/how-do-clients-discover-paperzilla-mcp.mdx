Start with `https://paperzilla.ai/api/mcp` from the docs, settings, or a published directory listing. Its authentication challenge points to protected-resource metadata and the OAuth issuer. After browser authorization, the SDK discovers the tool schemas with MCP. This is separate from OpenAPI. Use a current MCP SDK for both the 2026 per-request protocol and older standard clients. See the [reference](/api-reference/mcp).
