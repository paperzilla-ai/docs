Both.

For humans, Paperzilla provides app feed and email digests.

For agent or script workflows, Paperzilla provides:

- [CLI (`pz`)](/guides/cli)
- [RSS/Atom feeds](/guides/feeds)
- [MCP (`/api/mcp`)](/guides/mcp) for native tool calls

<Info>**Connect your agent with the Paperzilla plugin.** See [plugin setup](/guides/mcp) for Claude, ChatGPT, Codex, and OpenClaw.</Info>

You can use both modes on the same project.
