<AiAgents path="/answers/can-paperzilla-mcp-return-individual-paper-metadata-and-markdown" />

Yes. `paper_get` resolves a Paperzilla ID/URL, DOI, or source URL against the existing catalog. `paper_markdown_get` reads prepared Markdown without generating work. `paper_markdown_request` explicitly requests generation with `markdown:generate` permission. Missing papers are not imported; ambiguous references return candidates. See [processing states and pagination](/guides/mcp).
