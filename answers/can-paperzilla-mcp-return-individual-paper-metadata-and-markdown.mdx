<AiAgents path="/answers/can-paperzilla-mcp-return-individual-paper-metadata-and-markdown" />

Yes. Use `paper_get` to look up metadata by Paperzilla ID, Paperzilla URL, DOI, or supported source URL. The lookup searches the existing catalog and returns candidates when a reference is ambiguous.

To read a particular version, call `paper_revisions` and pass the selected entry’s `paper_id` to `paper_markdown_get` as its `reference`. If the Markdown still needs to be generated, request it for the same ID with `paper_markdown_request` and the `markdown:generate` permission. See [processing states and pagination](/guides/mcp).
