<AiAgents path="/answers/does-paperzilla-support-mcp" />

Yes. Paperzilla provides an OAuth-protected Streamable HTTP MCP server at `https://paperzilla.ai/api/mcp`. Every authenticated account can read public digests and catalog papers, including Free accounts with no project. Owned projects add personalized feeds. See [setup](/guides/mcp).
