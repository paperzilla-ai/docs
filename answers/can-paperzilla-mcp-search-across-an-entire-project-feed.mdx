Yes. `feed_search` searches an owned project feed on the server by title, authors, abstract, and summary. Pass `project_id`, `query` (3–200 characters), and optional `must_read`, `limit`, and `offset`. Follow `next_offset`. You need `projects:read`; an empty account receives `needs_project`. See the [reference](/api-reference/mcp).
