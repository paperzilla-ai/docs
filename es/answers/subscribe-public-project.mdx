<AiAgents path="/es/answers/subscribe-public-project" />

1. Abre la página de un proyecto público.
2. Haz clic en **Suscribirse**.
3. Revisa en el chat la configuración precargada.
4. Ajusta las categorías y palabras clave.
5. Guárdalo como proyecto propio.

No modificarás el proyecto del propietario original.
