Usa `pz feed search`.

Si aún no conoces el ID del proyecto, obtenlo primero:

```bash
pz project list
```

Para scripts y agentes de IA, `pz project list --json` devuelve una matriz resumida con `id`, `name`, `mode` y `visibility`.

Después, busca en toda la lista de un proyecto:

```bash
pz feed search --project-id <project-id> --query "latent retrieval"
```

Ejemplos útiles:

```bash
# Prefix matching
pz feed search --project-id <project-id> --query "Proxi"

# Only Must Read papers
pz feed search --project-id <project-id> --query "retrieval" --must-read

# Only starred papers
pz feed search --project-id <project-id> --query "retrieval" --feedback-filter starred

# JSON output for scripting
pz feed search --project-id <project-id> --query "latent retrieval" --json
```

Notas:

- la búsqueda cubre toda la lista del proyecto, no solo las páginas ya cargadas
- la búsqueda ordena primero por relevancia
- los términos de consulta usan coincidencia por prefijo
- el contenedor JSON incluye `items`, `limit`, `offset`, `has_more` y `query`

Consulta la [guía de CLI](/es/guides/cli) para ver la referencia completa de comandos.
