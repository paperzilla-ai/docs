Sí.

Paperzilla MCP admite dos herramientas por artículo:

- `paper_get` devuelve los metadatos y campos de estado de un artículo
- `paper_markdown` devuelve el Markdown del artículo cuando está listo

Si el Markdown aún no está listo, `paper_markdown` devuelve un resultado estructurado que indica si la generación se puso en cola o no está disponible.

Para buscar en toda la lista, usa `feed_search`. Es una función distinta de las herramientas por artículo de esta página.

Puedes buscar un artículo por:

- UUID del artículo
- identificador `short_id` del artículo
- elemento de la lista / `project_paper` identificado por UUID
- identificador del elemento de la lista / `project_paper` `short_id`
