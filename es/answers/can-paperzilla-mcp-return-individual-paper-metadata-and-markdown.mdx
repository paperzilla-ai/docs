Sí. Usa `paper_get` para buscar metadatos por ID o URL de Paperzilla, DOI o URL de una fuente compatible. La búsqueda consulta el catálogo existente y devuelve candidatos si la referencia es ambigua.

Para leer una versión concreta, llama a `paper_revisions` y pasa el `paper_id` de la versión elegida a `paper_markdown_get` en el parámetro `reference`. Si aún hay que generar el Markdown, solicítalo para ese mismo ID con `paper_markdown_request` y el permiso `markdown:generate`. Consulta los [estados y la paginación](/es/guides/mcp).
