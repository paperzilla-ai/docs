Sí. `paper_get` busca un ID/URL de Paperzilla, DOI o URL de fuente en el catálogo existente. `paper_markdown_get` lee Markdown preparado sin generar trabajo. `paper_markdown_request` solicita generación explícita con el permiso `markdown:generate`. Los artículos desconocidos no se importan y las referencias ambiguas devuelven candidatos. Consulta [estados y paginación](/es/guides/mcp).
