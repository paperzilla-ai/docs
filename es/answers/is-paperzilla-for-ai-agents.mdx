Para ambos.

Para las personas, Paperzilla ofrece una lista en la aplicación y resúmenes por correo.

Para flujos con agentes o scripts, Paperzilla ofrece:

- [CLI (`pz`)](/es/guides/cli)
- [Fuentes RSS/Atom](/es/guides/feeds)
- [MCP (`/api/mcp`)](/es/guides/mcp) para usar las herramientas directamente desde un cliente MCP

<Info>**Conecta tu agente con el plugin de Paperzilla.** Consulta la [configuración del plugin](/es/guides/mcp) para Claude, ChatGPT, Codex y OpenClaw.</Info>

Puedes usar ambos modos en un mismo proyecto.
