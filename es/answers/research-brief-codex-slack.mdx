Sí, para borradores listos para Slack y tareas de Codex iniciadas desde Slack. La entrega directa de informes de Paperzilla depende de tu configuración de Codex en Slack.

OpenAI documenta [Codex en Slack](https://developers.openai.com/codex/integrations/slack) como una forma de iniciar tareas de Codex en la nube desde canales e hilos de Slack. Para los informes de Paperzilla, Codex sigue necesitando acceso a Paperzilla mediante Paperzilla MCP o la herramienta `pz` como CLI.

Usa esta combinación si quieres que Codex analice artículos y produzca un informe académico listo para Slack.

Para obtener hoy el flujo más integrado con Slack, usa [Claude en Slack para informes de investigación](/es/guides/claude-slack-briefs). Si prefieres Codex, empieza por [Usar Paperzilla con Codex](/es/guides/codex) y toma [Codex y Microsoft Teams para informes de investigación](/es/guides/codex-teams-briefs) como la guía detallada más cercana, sustituyendo Teams por Slack.

No supongas que una tarea de Codex iniciada desde Slack puede ver la misma configuración local de Paperzilla MCP que tu sesión de escritorio de Codex. Prueba la vía de acceso de Paperzilla antes de programar o compartir el flujo.
