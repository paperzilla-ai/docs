Llame a `feed_search`.

Como mínimo, proporciona:

- `project_id`
- `q`

También puedes proporcionar:

- `feedback_filter`
- `must_read`
- `limit`
- `offset`

La respuesta contiene:

- `items`
- `limit`
- `offset`
- `has_more`
- `query`

Usa `offset` y `limit` para obtener la página siguiente solo cuando `has_more` sea `true`.

La búsqueda usa coincidencia por prefijo, por lo que `Proxi` encuentra `Proximity`.

Si el cliente MCP todavía usa nombres heredados con puntos, `feed.search` sigue funcionando. Las integraciones nuevas deben preferir `feed_search`.
