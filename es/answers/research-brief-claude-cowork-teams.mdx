Sí, para borradores con contexto de Teams. La entrega directa depende del conector o la automatización que uses.

El [conector de Microsoft 365](https://support.claude.com/en/articles/12542951-enable-and-use-the-microsoft-365-connector) de Claude puede usar como contexto conversaciones de Teams. Combínalo con Paperzilla MCP en Claude Cowork para preparar un informe académico listo para Microsoft Teams.

Usa [Claude en Slack para informes de investigación](/es/guides/claude-slack-briefs) como la guía detallada de Cowork más cercana. Sustituye Slack por el contexto de Microsoft 365 o Teams y mantén el resultado como borrador listo para Teams salvo que hayas probado la entrega directa.

Si el requisito principal es entregar directamente a un canal de Teams, [OpenClaw y Microsoft Teams](/es/answers/research-brief-openclaw-teams) puede resultar más adecuado.
