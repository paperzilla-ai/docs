Sí.

<Info>**Conecta Paperzilla primero.** [Instala el plugin de Paperzilla MCP en OpenClaw](/es/guides/openclaw-mcp#install-the-paperzilla-mcp-plugin) para conectar tu cuenta. Después vuelve a esta página para continuar con Slack.</Info>

OpenClaw admite [Slack como canal](https://docs.openclaw.ai/channels/slack). OpenClaw ejecuta la tarea programada, lee la lista del proyecto mediante el plugin de Paperzilla y envía el informe a Slack. También puedes usar la configuración con la CLI de la guía de Telegram.

Usa [OpenClaw y Telegram para informes de investigación](/es/guides/openclaw-telegram-briefs) como guía detallada más cercana. Sustituye la configuración del canal y el destino de Telegram por la configuración de tu canal de Slack en OpenClaw.

Este flujo resulta adecuado si quieres una puerta de enlace autoalojada capaz de enviar el mismo informe académico de Paperzilla a varias herramientas de chat.
