Motivos habituales:

- El proyecto aún se está procesando
- El proyecto está pausado
- Los filtros son demasiado estrictos
- El tema es muy específico

Prueba lo siguiente:

1. Espera al siguiente ciclo de procesamiento.
2. Comprueba que el proyecto está activo y no pausado.
3. Amplía ligeramente el texto de interés.
4. Quita palabras clave de exclusión demasiado restrictivas.
5. Activa los artículos adyacentes.
