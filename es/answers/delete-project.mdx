---
title: "¿Cómo elimino un proyecto?"
description: "Elimina un proyecto de Paperzilla desde su página mediante la acción de eliminación."
keywords: ["eliminar proyecto", "quitar", "permanente"]
---

import { AiAgents } from '/es/snippets/ai-agents.mdx';

<AiAgents path="/es/answers/delete-project" />

1. Abre el proyecto.
2. Desplázate hasta la sección de eliminación.
3. Haz clic en **Eliminar proyecto** (acción para eliminar el proyecto).
4. Confirma.

La eliminación borra el proyecto y sus entregas, artículos y configuraciones relacionados.

Esta acción es permanente.
