Usa `pz` directamente en Claude Code.

Versión breve:

1. Instala la [CLI de Paperzilla](/es/guides/cli) y ejecuta `pz login`.
2. Comprueba que `pz` funciona en el mismo entorno de terminal que Claude Code.
3. Pide a Claude Code que use `pz` para tareas de Paperzilla.

Flujo habitual:

```bash
pz project list --json
pz feed search --project-id <project-id> --query "retrieval evaluation" --json
pz paper <paper-id> --json
pz rec <project-paper-id> --markdown
```

`pz project list --json` devuelve una matriz resumida de proyectos que suele bastar para elegir el `project-id` correcto.

Usa `pz paper` para los metadatos del artículo canónico.

Usa `pz rec --markdown` después de buscar en la lista cuando necesites Markdown con contexto del proyecto. Esta vía puede poner en cola la generación si aún no está lista.

No necesitas un conector personalizado de Paperzilla para esta vía de CLI. Claude Code ya puede ejecutar comandos del shell en tu espacio de trabajo.

Si prefieres la vía de llamadas remotas a herramientas en Claude, usa [Paperzilla MCP con Claude](/es/guides/claude).

Para ver la referencia completa de comandos de la CLI, consulta la [guía de CLI](/es/guides/cli).
