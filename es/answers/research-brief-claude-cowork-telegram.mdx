Sí, pero identifica con precisión qué superficie de Claude se encarga de Telegram.

Usa Claude Cowork con Paperzilla MCP para crear un informe académico listo para Telegram.

Para la entrega por Telegram, Anthropic documenta [Claude Code Channels](https://code.claude.com/docs/en/channels) con un plugin de Telegram. Este envía mensajes de Telegram a una sesión activa de Claude Code y permite que Claude responda por Telegram.

No es exactamente lo mismo que una tarea programada de Cowork que publique directamente en Telegram. Para un informe recurrente de Cowork, mantén el resultado como borrador listo para Telegram salvo que hayas probado Claude Code Channels, OpenClaw u otro puente de Telegram en tu configuración.

Si la entrega por Telegram es el requisito principal, usa [OpenClaw y Telegram para informes de investigación](/es/guides/openclaw-telegram-briefs) o Claude Code Channels. Si lo principal es Claude Cowork, usa [Claude en Slack para informes de investigación](/es/guides/claude-slack-briefs) como la guía de Cowork más cercana, sustituyendo Slack por la vía probada de Telegram.
