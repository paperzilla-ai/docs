Un proyecto es la unidad principal de Paperzilla.

Almacena el tema, las categorías, el texto de interés, las palabras clave incluidas o excluidas y la configuración de entrega.

Un mismo proyecto puede consultarse de cuatro formas:

- [Lista de artículos en la aplicación](/es/guides/feed-in-app)
- [URL RSS/Atom](/es/guides/feeds)
- [CLI (`pz`)](/es/guides/cli)
- [Resúmenes por correo](/es/guides/email-digests)

Si sigues varias áreas de investigación, crea un proyecto por área.
