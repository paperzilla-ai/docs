Sí, para borradores listos para Microsoft Teams. El contexto de Teams y la publicación directa dependen de la aplicación o el plugin de Microsoft Teams y de los permisos de tu espacio de trabajo.

Usa esta versión del flujo: Codex puede utilizar Paperzilla MCP para preparar informes académicos destinados a Microsoft Teams. Si la [aplicación Microsoft Teams para ChatGPT](https://help.openai.com/en/articles/12552368-microsoft-teams-app-for-chatgpt) o el plugin de Codex están conectados y tienen activadas las acciones necesarias, Codex también puede usar el contexto de Teams o publicar tras una confirmación.

Empieza con borradores. No des por sentada la publicación directa en Teams hasta probarla en tu propio espacio de trabajo.

Para conocer el flujo completo, consulta [Usar Codex y Microsoft Teams para informes de investigación](/es/guides/codex-teams-briefs).
