Añade Paperzilla como conector personalizado en Claude.

Versión breve:

1. Crea o copia tu **Clave de API de MCP** desde el [panel](https://paperzilla.ai/dashboard).
2. En Claude, abre **Settings** > **Connectors**.
3. Añade un conector personalizado llamado `Paperzilla`.
4. Usa `https://paperzilla.ai/api/mcp/?key=pzmcp_...` como URL del conector.
5. Después de configurarlo, establece el conector en **Always allow** para que Claude use las herramientas sin pedir permiso en cada llamada.

Una vez conectado, Claude puede usar:

- `projects_list`
- `projects_get`
- `feed_get`
- `feed_search`
- `feed_atom_url`
- `paper_get`
- `paper_markdown`

Usa `feed_search` cuando quieras que Claude busque por título, autor, resumen del artículo o resumen con IA en toda la lista del proyecto.

Para conocer el procedimiento completo, consulta [Usar Paperzilla MCP con Claude](/es/guides/claude).
