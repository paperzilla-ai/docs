Usa la conexión MCP OAuth de Paperzilla para herramientas de investigación o la [guía CLI](/es/guides/cli) para tareas de terminal.

## Conexión MCP

En Codex añade un servidor MCP HTTP remoto llamado `paperzilla` con URL `https://paperzilla.ai/api/mcp` y completa OAuth. El plugin Paperzilla del marketplace de Paperzilla incluye la misma URL. Instala el paquete nuevo, elimina la configuración anterior con clave e inicia sesión.

Para la integración completa solicita `catalog:read projects:read markdown:generate offline_access`. No hace falta una variable de entorno con una clave API. Deja las credenciales OAuth en el almacenamiento seguro del cliente.

Pide un digest público, un artículo del catálogo o una búsqueda en un feed propio. El acceso público no requiere proyectos. `paper_markdown_get` lee; `paper_markdown_request` solicita generación explícita. Esta versión MCP no modifica proyectos ni valoraciones ni importa artículos.

## Tareas con la CLI

La CLI tiene su propio inicio de sesión y sus propios permisos. Sigue la [configuración CLI](/es/guides/cli), ejecuta `pz --help` y pide a Codex que utilice el comando documentado. No uses credenciales MCP contra los endpoints API ordinarios.

Consulta [configuración, permisos y reconexión](/es/guides/mcp) y la [referencia](/es/api-reference/mcp).
