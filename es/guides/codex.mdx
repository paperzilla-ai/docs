Usa la conexión MCP OAuth de Paperzilla para herramientas de investigación o la [guía CLI](/es/guides/cli) para tareas de terminal.

<Info>**Empieza con el plugin de Paperzilla.** El plugin configura el servidor MCP por ti. Sigue los [pasos de instalación](#install-the-paperzilla-plugin) para conectar tu cuenta.</Info>

## Instala el plugin de Paperzilla {#install-the-paperzilla-plugin}

Añade el [marketplace de Paperzilla](https://github.com/paperzilla-ai/codex-plugins#install) desde tu terminal.

```bash
codex plugin marketplace add paperzilla-ai/codex-plugins
```

Abre **Plugins** en Codex, elige **Paperzilla** en el marketplace de Paperzilla e instálalo. Sigue las instrucciones de inicio de sesión para conectar tu cuenta de Paperzilla.

## Conexión MCP {#mcp-connection}

Para configurarlo manualmente, añade en Codex un servidor MCP HTTP remoto llamado `paperzilla` con URL `https://paperzilla.ai/api/mcp` y completa OAuth. Si tienes una configuración antigua con clave API, sustitúyela por esta conexión OAuth.

Para la integración completa solicita `catalog:read projects:read feedback:write markdown:generate offline_access`. No hace falta una variable de entorno con una clave API. Deja las credenciales OAuth en el almacenamiento seguro del cliente.

Pide un digest público, un artículo del catálogo o una búsqueda en un feed propio. El acceso público no requiere proyectos. `paper_markdown_get` lee; `paper_markdown_request` solicita generación explícita. Usa `feedback_set` o `feedback_clear` solo cuando quieras valorar, marcar como favorito o borrar la valoración de un artículo de tu propio feed. Requiere `feedback:write`; reconecta para aprobarlo si tu conexión es anterior a estas herramientas. Esta versión MCP no crea ni edita proyectos ni importa artículos.

## Tareas con la CLI

La CLI tiene su propio inicio de sesión y sus propios permisos. Sigue la [configuración CLI](/es/guides/cli), ejecuta `pz --help` y pide a Codex que utilice el comando documentado. No uses credenciales MCP contra los endpoints API ordinarios.

Consulta [configuración, permisos y reconexión](/es/guides/mcp) y la [referencia](/es/api-reference/mcp).
