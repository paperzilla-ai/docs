Schedule your AI agent to check a Paperzilla project and tell you which new papers are worth reading. Paperzilla tracks your topic and ranks papers in your feed. Your agent runs the scheduled task and prepares the brief.

## Test the brief in chat

<Info>**Connect Paperzilla before scheduling.** Follow the plugin setup for [Claude](/guides/claude#open-the-connection-setup), [Codex](/guides/chatgpt-codex-briefs#use-paperzilla-in-codex), or [OpenClaw](/guides/openclaw-mcp#install-the-paperzilla-mcp-plugin). For other agents, [connect Paperzilla through MCP](/guides/ai-agent-briefs). Then return here to test and schedule your brief.</Info>

1. Make sure the project belongs to the account you connected and that its tracking is active.
2. Pick the project, cadence, and timezone. Set the lookback window in the prompt to cover the time between runs. A weekday schedule can use three days on Monday and one day on the other weekdays.
3. Run the prompt below in chat. Replace **Robotics evaluation** with your project name and adjust the research focus.

> Use my Paperzilla project named Robotics evaluation. Check papers added to its feed since the last successful brief. If you can't see that run, use a three-day lookback on Monday and a 24-hour lookback on other weekdays. Pick up to three papers relevant to evaluating robots in unfamiliar environments. For each, give the title, source link, and one reason to read it. State the time window you checked. If nothing matches, say so. Return the brief for me to review.

## Verify the scheduled run

1. Run the saved task on demand. Check the project, sources, and first delivery destination. If the task pauses for approval, check whether your agent can allow the Paperzilla read-only calls needed for the brief.
2. Review the first automatic run in your agent's history. If it reports no new papers, compare the time window with your project feed. If the task never started, check the timezone, whether the schedule is enabled, and whether any required app or host was running.
3. Start with a private result or draft. When you're ready to deliver it to a channel, use the dedicated [Slack](/guides/claude-slack-briefs), [Teams](/guides/codex-teams-briefs), or [Telegram](/guides/openclaw-telegram-briefs) walkthrough and verify the recipient.
